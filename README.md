# ИИ-ассистент компьютерного сервиса

**Цель**: Автоматизация приёма клиентов и записи на ремонт компьютерной техники.

**Функционал**:
1. Осмысленный диалог через нейросеть с поддержкой контекста.
2. Ответы на вопросы по базе знаний (услуги, цены, гарантии, адреса).
3. Запись на диагностику/ремонт с авто-добавлением в Google Календарь.

**Технологический стек**:
- **Qwen**: Генерация системного промпта и структурирование базы знаний (этап разработки).
- **Suvvy.ai**: Хостинг ассистента, диалоговый движок, интеграции.
- **Google Calendar API**: Синхронизация записей.

**Ключевые данные при записи**: имя, телефон, тип устройства, описание проблемы, дата/время.

**Безопасность**: Обработка данных по ФЗ-152, доступ по ролям, логирование.

**Этапы**: Подготовка контента → Настройка в Suvvy → Интеграция календаря → Тест → Запуск.

**Ограничения**: Сложные технические вопросы эскалируются оператору; точность зависит от актуальности базы знаний.
